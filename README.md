# Class Fund Management System - BJ3 (โรงเรียนบรรหารแจ่มใสวิทยา 3) 🏫💜

ระบบจัดการเงินห้องเรียนและเช็คชื่อค่าห้องเรียน โรงเรียนบรรหารแจ่มใสวิทยา 3 รองรับ 77 ห้องเรียน (มัธยมศึกษาปีที่ 1 ถึง 6) พัฒนาด้วย Next.js (App Router), Tailwind CSS (Pastel tone) พร้อมนำไป Deploy บน Vercel ได้ทันที

---

## ✨ คุณสมบัติเด่น (Features)

1. **รองรับ 77 ห้องเรียนครบทุกระดับชั้น (Multi-Room Dynamic Routing)**:
   - ม.1: 1/1 - 1/15 (15 ห้อง)
   - ม.2: 2/1 - 2/15 (15 ห้อง)
   - ม.3: 3/1 - 3/15 (15 ห้อง)
   - ม.4: 4/1 - 4/11 (11 ห้อง)
   - ม.5: 5/1 - 5/11 (11 ห้อง)
   - ม.6: 6/1 - 6/10 (10 ห้อง)
   - ใช้ Dynamic Route `/[room]` (เช่น `/3-15`, `/1-1`) โดยข้อมูลแยกเป็นอิสระต่อกันในแต่ละห้อง

2. **ระบบเข้าสู่ระบบ (Login Portal)**:
   - **Username**: เลขห้อง (เช่น `3/15`, `1/1`)
   - **Password**: เลขห้อง + `BJ3` (เช่น `3/15BJ3`, `1/1BJ3`)
   - มีแผงเลือกห้องด่วนตามระดับชั้น ม.1 - ม.6 เพื่อความสะดวกรวดเร็วในการทดสอบ

3. **แดชบอร์ดห้องเรียนสาธารณะ (Public Room Dashboard - `/[room]`)**:
   - การ์ดสรุป 3 ยอด: ยอดเงินคงเหลือรวม, ยอดรายรับรวม, ยอดรายจ่ายรวม (โทนพาสเทล)
   - สรุปความคืบหน้าการเก็บเงินห้อง (จำนวนคนที่จ่ายแล้ว vs ค้างชำระ พร้อมเปอร์เซ็นต์)
   - **แสดงวันที่ตามรูปแบบ พ.ศ. (DD/MM/YYYY) เท่านั้น (ไม่มีเวลา)**
   - รายชื่อนักเรียนที่ค้างชำระ (Mock data เช่น "เลขที่ 1 (Student 1)" โดยไม่เปิดเผยชื่อจริง)
   - ตาราง 5 รายการเคลื่อนไหวล่าสุด พร้อมทางลัดไปยังหน้าประวัติทั้งหมด

4. **หน้าประวัติเงินห้องสาธารณะ (Public History - `/[room]/history`)**:
   - แสดงตารางประวัติการทำรายการทั้งหมด พร้อมตัวกรอง (ทั้งหมด / เงินห้อง / รายรับ / รายจ่าย)
   - ระบบค้นหาตามชื่อรายการหรือหมวดหมู่
   - แสดงวันที่แบบ พ.ศ. ชัดเจน

5. **ระบบเหรัญญิกสำหรับจัดการเงินห้อง (Private Treasurer Portal - `/[room]/treasurer`)**:
   - กั้นสิทธิ์ด้วย **รหัส PIN เหรัญญิก** (PIN เริ่มต้นคือ `1234`) พร้อม Keypad ป้อนรหัสและจดจำเซสชันในเบราว์เซอร์
   - **ระบบเช็คชื่อจ่ายเงินห้อง**: ติ๊กถูกรายบุคคล, มีปุ่ม "เลือกชำระทั้งหมด" / "ยกเลิกทั้งหมด", คำนวณยอดเงินรวมอัตโนมัติ, พร้อมตัวเลือกบันทึกเป็นรายการเงินห้องลงประวัติทันที
   - **ระบบบันทึกรายรับ - รายจ่าย**: เพิ่ม, แก้ไข, และลบรายการเงินห้อง (เช่น ซื้อไม้กวาด, ค่าถ่ายเอกสารชีท, เงินสนับสนุน)
   - **การตั้งค่า**: เปลี่ยนรหัส PIN เหรัญญิก และปรับอัตราค่าห้องเรียนต่อคน

6. **ธีมดีไซน์มินิมอลพาสเทล (Pastel Theme)**:
   - สีหลัก (Primary Purple): `#C084FC`
   - สีสำเร็จ (Success Mint): `#50F2C8`
   - สีแจ้งเตือน (Danger Coral): `#FF96A8`
   - พื้นหลัง (Background): `#F8F5FB`
   - รองรับการใช้งานทั้งบนมือถือ (Mobile Responsive), แท็บเล็ต, และคอมพิวเตอร์

## 🚀 วิธีการทดสอบในเครื่องและการ Deploy บน Vercel

### 1. ทดสอบในเครื่อง (Local Development)
```bash
cd bj3-class-fund
npm install
npm run dev
```
เปิดเบราว์เซอร์ไปที่: `http://localhost:3000`

### 2. นำขึ้น GitHub และ Deploy บน Vercel
1. นำโฟลเดอร์โปรเจกต์นี้ขึ้น GitHub Repository ของคุณ
2. เข้าไปที่ [Vercel Dashboard](https://vercel.com)
3. กด **Add New Project** แล้ว Import Repository จาก GitHub
4. Vercel จะตรวจพบว่าเป็น Next.js อัตโนมัติ (Build Command: `next build`)
5. กด **Deploy** — ระบบจะพร้อมใช้งานออนไลน์ทันที!

### 3. การอัปเกรดเป็น Supabase Database (ทางเลือก)
หากต้องการเปลี่ยนจากการเก็บข้อมูลจำลอง (Mock DB / LocalStorage) เป็นฐานข้อมูล PostgreSQL จริง:
1. สร้างโปรเจกต์บน [Supabase](https://supabase.com)
2. เปิดเมนู **SQL Editor** แล้วคัดลอกคำสั่งจากไฟล์ `supabase_schema.sql` ไปรัน
3. เพิ่ม Environment Variables ใน Vercel สำหรับเชื่อมต่อ Supabase Client (`@supabase/supabase-js`)
